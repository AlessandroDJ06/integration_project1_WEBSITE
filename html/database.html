Onze database

Achter de schermen van Zaroc draait een krachtige SQL-database. Hier slaan we alle belangrijke gegevens veilig en gestructureerd op, van spelersprofielen tot highscores en actuele spelstatistieken. Op deze pagina geven we je een kijkje onder de motorkap en laten we zien hoe onze data is opgebouwd.

Onze database

SQL-database

Een SQL-database werkt als een supergeorganiseerd digitaal archief vol overzichtelijke tabellen. In plaats van alle Zaroc-data op één grote hoop te gooien, splitsen we het netjes op: we hebben bijvoorbeeld één tabel voor alle spelers en één voor alle games. Omdat het een relationele database is, zijn al deze tabellen logisch met elkaar verbonden. Via de programmeertaal SQL kunnen we razendsnel informatie opvragen en combineren. Zo koppelen we met één simpele query direct de juiste speler aan de juiste games, zodat de game altijd vlekkeloos en snel blijft draaien!

Queries

Queries zijn de gerichte opdrachten die we naar de database sturen om gegevens op te halen, toe te voegen of aan te passen. Wij maken hierbij specifiek gebruik van prepared statements. Dit is een techniek waarbij de SQL-code en de ingevoerde data strikt gescheiden blijven. Het grote voordeel hiervan is optimale veiligheid: het beschermt ons systeem tegen zogenaamde 'SQL-injecties' (hackpogingen). Daarnaast verbetert het de prestaties, omdat de database de opdracht sneller kan hergebruiken.

Utils

Omdat er vaak dezelfde algemene methodes nodig zijn om de vele queries uit te voeren hebben wij een set algemene methodes gemaakt die van overal uit het spel uitgevoerd kunnen worden zodat alles zo vlot mogelijk verloopt.

Leaderboard

Zoals elke goede game heeft ons spel ook een leaderboard waar je jouw scores kan vergelijken met die van je vrienden en proberen de beste te zijn. Ons leaderboard kan gesorteerd worden op verschillende criteria zonder elke keer de data terug aan de database te vragen door dat we de data tijdelijk lokaal bijhouden. Zo Kan je super snel iedereen laten zien hoe goed je bent!
