Multiplayer

Stel je voor, je wilt zo graag zaroc spelen tegen 1 van je vrienden maar jullie zijn niet bij elkaar. Wij hebben hier de oplossing voor. Inderdaad Multiplayer!

Extra info

Hoe werkt het

Om dit te laten werken maken we gebruik van de database en een techniek die pollen noemt. Pollen is eigenlijk heel simpel! Wanneer je een game start checkt de database om de 2seconden of er een nieuwe move is gebeurd, en als dit het geval is gebruikt hij dezelfde logica die we ook gebruiken bij unfinishedgames om de game op te zetten!

Hoe join je elkaar

Als je op het multiplayer menu klikt krijg je 2 opties, je kan een game joinen of starten. Als je een game start krijg je een code die de andere persoon moet ingeven. En logisch gezien als je een game joint krijg je de optie om een code in te geven. Wanneer je dit doet start de lobbyPoller, en die checkt of je succesvol gejoined bent! Wanneer dat gebeurt is kan de host de game starten en voila! Veel speel plezier!
