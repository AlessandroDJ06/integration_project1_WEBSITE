Onze database slaat alles op wat er tijdens een game gebeurt. Zo kunnen wij statistieken bijhouden, unfinished games hervatten en multiplayer mogelijk maken. Het Entity Relationship Diagram hieronder toont hoe onze database samenhangt.

Relaties en toelichting

Relaties

We gebruiken de tussentabel GAME_PARTICIPATION om een veel-op-veel relatie tussen PLAYERS en GAMES op te lossen. Hierdoor kan één game meerdere spelers hebben, en kan één speler aan meerdere games meedoen. Daarnaast slaan we hier ook spel specifieke data op, zoals met welke kleur pion de speler speelde en of hij de winnaar was.

TURNS en MOVES vormen een hiërarchie. 1 game heeft veel beurten, en 1 beurt heeft maximaal twee zetten. Dit is telkens een één-op-veel relatie.

GAME_ROOMS heeft een 1 op 1 relatie met GAMES. 1 room hoort bij exact 1 game. De tabel verwijst via twee aparte foreign keys (host_id en guest_id) naar PLAYERS, zodat de twee rollen in een online game duidelijk onderscheiden zijn. Beide zijn een veel-op-één relatie met PLAYERS. Één speler kan meerdere keren host of gast zijn.

Toelichting

Wachtwoorden in de PLAYERS tabel worden gehasht opgeslagen via BCrypt. Ze gaan nooit als plain text over het netwerk, de databaseverbinding is beveiligd met SSL dus zelfs de hashwaarde is niet leesbaar.

De room_code in GAME_ROOMS is een unieke varchar in plaats van een gewone integer. Zo kunnen wij spelers een korte, leesbare code geven om samen in een lobby te komen. De code wordt door de server gegenereerd als een willekeurige hexadecimale string en is gegarandeerd uniek door de UQ-constraint.

De kolommen play_style en difficulty staan allebei in PLAYERS. difficulty is enkel ingevuld voor AI en bepaalt hoe diep het AI-model nadenkt. play_style is enkel ingevuld voor menselijke spelers en wordt na een game berekend op basis van het aantal agressieve zetten. De niet ingevulde waarden zijn dus null.

start_location en end_location in MOVES worden opgeslagen als coördinaaten in het formaat x,y. Dit zijn de posities van de pen op het bord voor en na de zet.
